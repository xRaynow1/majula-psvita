# Majula — PS Vita

**Thou hast fought well, weary warrior... Come, rest awhile.**
An interactive ambient scene inspired by Majula from Dark Souls II for PlayStation Vita, built in Lua with `lpp-vita`.

<img width="1920" height="1080" alt="majula" src="https://github.com/user-attachments/assets/472b9ba1-e3cb-404e-98b0-b8c2e4c2d102" />

## Featuress
- Full-screen looping video background (960×544) with opening fade-in
- Looping ambient soundtrack
- Interactive touch-triggered glowing embers (with organic wave motion and flickering)

## Installation

### Method 1: Using the `.vpk` file (Recommended)
1. Download the latest `.vpk` file from the **[Releases](../../releases)** tab.
2. Transfer the `.vpk` to your PS Vita via **VitaShell** (USB or FTP).
3. Install the file by pressing `X` in VitaShell, then launch the bubble from the LiveArea.

OR : 

### Method 2: Using the `.zip` archive (Install Folder)
1. Download the `.zip` archive from the **[Releases](../../releases)** tab (or click **Code → Download ZIP** on this repository).
2. Extract the `.zip` on your PC so you have a folder containing `eboot.bin`, `index.lua`, and `sce_sys/`.
3. Transfer the extracted folder to `ux0:` on your PS Vita via **VitaShell** (USB or FTP).
4. Highlight the folder in VitaShell, press `△` (Triangle) → **More** → **Install folder**, then confirm with `X`.

## Controls
- **Touchscreen:** Spawn glowing embers
- **START:** Exit cleanly to the LiveArea
